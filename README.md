# **Web of Lies**

A deduction party game! Made for the UIUC Gamebuilders Fall 2026 Game Jam (theme: Web)

**Made Using**

- HTML5 and JS Canvas2d (frontend)
- NodeJS (ExpressJS and SocketIO) (backend)
- Asesprite and Krita (assets)
